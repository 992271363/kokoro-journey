# Kokoro Journey

> 一场理解自己数字生活的旅程。

Kokoro Journey 是一款个人电脑活动记录与分析工具。它持续记录用户在电脑上的使用行为，
并将原始活动数据整理为可理解的信息，帮助用户了解自己的数字生活习惯。

项目最初只是一个简单的个人计时器，随着需求的积累，逐步发展为一个用于记录、分析与回顾
电脑使用方式的桌面工具。

---

## 功能特性

### 活动记录
- 监控当前使用中的应用程序，记录运行时长与焦点时长
- 追踪前台窗口活动，按窗口标题细分焦点区间
- 暂离检测：无键鼠操作达到设定时长后自动暂停计时
- 会话与焦点明细持久化到本地数据库；保存失败的会话进入队列自动重试

### 应用管理
- 添加与删除监控应用，支持「拾取窗口」拖拽添加
- 全局或单个应用的监控启停
- 重命名显示名称、更换追踪目标进程、修改启动路径
- 路径标准化，并标记 路径不存在 / 未监视 / 未运行 状态

### 分组与颜色标记
- 应用与分组的自定义多对多关系
- 分组按钮支持拖动排序，数量过多时自动折叠为溢出菜单
- 六种护眼颜色标记

### 统计分析
- 时间范围：最近（当月每天）、每周、每月、全部历史
- 三种视图：列表、柱状图、饼状图
- 支持按焦点时长或运行时长排序

### 数据管理
- 导出为 db / json / zip；导入支持覆盖导入与合并导入
- 导入时进行冲突与重名检测，并提供确认与自动备份
- 清除全部数据、清除失败队列
- 数据目录可自定义；更换位置时自动迁移（失败时保留源文件）
- 自动备份，保留最近五份

### 数据同步
- 客户端与服务端通过 REST API 同步，支持登录、登出与后台定时同步
- 会话分批上传，避免大请求导致的超时或体积超限
- 服务端按会话唯一键幂等去重，避免重复计入

### 界面与体验
- 浅色、深色、跟随系统三种主题，支持高 DPI
- 系统托盘、关闭行为设置、开机自启、启动时最小化
- 首次配置向导与数据目录边界校验
- 列表 Ctrl+滚轮缩放、窗口大小与位置记忆、状态栏版本号
- 空状态引导页与自适应工具栏

### 打包与分发
- 使用 Nuitka 打包为无控制台主程序与日志控制台
- 使用 Inno Setup 生成安装包，按用户安装（无需管理员权限）
- 卸载时可选保留或删除用户数据，采用选择性删除以避免误删
- 单实例锁与便携模式（portable.txt）

## 项目架构

```
桌面客户端 (PySide6) ── REST API ──▶ 后端服务 (FastAPI) ──▶ 数据库 (MariaDB)
                                          ▲
                                   Nginx · Web 仪表盘 (Vue)
```

---

## 技术栈

- 客户端：Python、PySide6、psutil、pywin32、SQLite、SQLAlchemy、requests
- 服务端：FastAPI、SQLAlchemy、MariaDB、JWT
- Web：Vue、Nginx
- 打包与部署：Nuitka、Inno Setup、Docker、Docker Compose

---

## 安装与运行

- 安装：运行 KokoroJourneySetup-*.exe，默认安装到用户目录，无需管理员权限
- 首次启动会引导选择数据存储位置
- 卸载：可选择保留或删除用户数据

从源码运行：

```
python client/main.py
```

## 项目理念

大多数时间管理工具关注的是：

> “我有没有浪费时间？”

而 Kokoro Journey 更关注：

> “我的时间去了哪里？”

它通过长期记录电脑使用行为，帮助用户发现自己的数字生活规律，而不是简单地评价用户是否高效。
