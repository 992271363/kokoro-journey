# Kokoro Journey

> 一场理解自己数字生活的旅程。

Kokoro Journey 是一个个人电脑活动记录与分析工具。

它会记录用户在电脑上的使用行为，将原始的活动数据转化为可理解的信息，帮助用户了解自己的数字生活习惯。

这个项目最初只是一个简单的个人计时器，随着不断开发和需求增加，逐渐发展成为一个用于记录、分析和反思电脑使用方式的工具。

---

## 功能特性

### 活动记录

* 监控当前使用中的应用程序
* 记录应用使用时间
* 追踪前台窗口活动
* 保存活动会话数据

### 数据同步

* 本地数据缓存
* 客户端与服务端同步
* 集中化活动数据管理

### 数据分析

开发中

计划支持：

* 每日活动总结
* 应用使用排行
* 时间分布可视化
* 历史使用趋势
* AI 辅助活动分析

## 项目理念

大多数时间管理工具关注的是：

> “我有没有浪费时间？”

而 Kokoro Journey 更关注：

> “我的时间去了哪里？”

通过长期记录电脑使用行为，希望帮助用户发现自己的数字生活规律，而不是简单地评价用户是否“高效”。

---

## AI 分析（计划）

Kokoro Journey 计划支持用户自行配置 AI API。

可能的应用场景：

* 生成每日电脑使用总结
* 分析长期使用习惯
* 提供个性化洞察

用户可以接入自己的 AI 服务，而不是依赖固定的平台。
